# Dossier des Images et Photos - BENIN-PEPI

Placez ici toutes les photos de vos pépinières, logos, plants et pépiniéristes.

## 📸 Comment lier une image à une pépinière ?
1. Déposez votre image dans ce dossier : `/public/assets/pepinieres/` (ex: `ma_pepiniere_abomey.jpg`).
2. Dans le fichier GeoJSON ou dans le formulaire d'ajout/modification, indiquez le chemin :
   `"/assets/pepinieres/ma_pepiniere_abomey.jpg"`
3. Vous pouvez également coller directement des URLs d'images hébergées en ligne ou utiliser l'outil d'import intégré dans l'application.
